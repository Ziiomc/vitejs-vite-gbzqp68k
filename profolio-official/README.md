# ProFolio · interfaz premium oficial

Esta carpeta contiene la capa visual aprobada para unificar Ruta de las Llaves / Homefolio / ProFolio bajo una sola experiencia.

- Mantiene la lógica operativa del Market Map existente.
- Conserva Open Tour, Turbo, publicación de propiedades, favoritos, videos por sector y delimitaciones territoriales.
- Añade el sistema visual premium aprobado: navegación oscura, burgundy intenso, acentos dorados, hero inmobiliario, métricas, Off-Market y accesos rápidos.
- `ui-premium.js` agrega navegación y módulos complementarios sin duplicar la lógica principal.

Los scripts funcionales se apuntan temporalmente al despliegue inmutable de producción `ruta-las-llaves-aickqgx5z-ignacio-s-ziio.vercel.app` para evitar perder funcionalidades durante la migración de la fuente original a GitHub.
